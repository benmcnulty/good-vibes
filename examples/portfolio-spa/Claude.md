# Claude Guide – Portfolio SPA Example

This file describes the vibe-coded plan for building the **Portfolio SPA Example** showcase application.

## Purpose
- Demonstrate a comprehensive portfolio website with modern design
- Showcase vibe coding principles in a professional context
- Provide a fully functional example with rich interactivity
- Serve as a template for creative developers

## Key Features

### Design & User Experience
- **Hero Section**: Eye-catching introduction with gradient text effects and call-to-action
- **Modern Design**: Uses CSS custom properties for consistent theming
- **Responsive Layout**: Mobile-first design that adapts beautifully to all screen sizes
- **Smooth Animations**: Fade-in transitions, hover effects, and micro-interactions
- **Professional Typography**: Clean, modern font hierarchy with proper spacing

### Content Sections
- **Home**: Hero section with professional introduction and portfolio overview
- **Projects**: Grid layout showcasing 6 sample projects with technology tags and links
- **Skills**: Organized skill categories covering frontend, design, tools, and soft skills
- **Experience**: Timeline-based layout showing professional journey with company details
- **Contact**: Interactive contact form with validation and contact information cards

### Technical Implementation
- **Navigation**: Single-page application with smooth section switching
- **Project Cards**: Interactive cards with hover effects and gradient backgrounds
- **Skills Grid**: Categorized skill lists with checkmark icons and color coding
- **Experience Timeline**: Visual timeline with positioning and hover states
- **Contact Form**: Functional form with validation and submission handling
- **Accessibility**: Proper ARIA attributes, keyboard navigation, and semantic HTML

### Interactive Features
- **Form Handling**: Contact form with client-side validation and submission feedback
- **Card Interactions**: Hover effects on project cards and skill categories
- **Smooth Scrolling**: Enhanced navigation with smooth transitions
- **Loading Animations**: Page load animations for polished user experience
- **Button Effects**: Gradient buttons with hover states and transform effects

### Sample Content
- **Portfolio Projects**: 6 diverse projects including blog platform, gallery, chat interface, weather dashboard, task manager, and design system
- **Professional Experience**: 4 career positions with detailed descriptions and timelines
- **Skill Categories**: Comprehensive skill lists across multiple disciplines
- **Contact Information**: Professional contact details and interactive form

## Architecture
- **CSS Custom Properties**: Consistent color scheme and spacing system
- **Grid Layouts**: Modern CSS Grid for responsive project and skill grids
- **Flexbox Navigation**: Flexible navigation system with proper accessibility
- **JavaScript Modules**: Well-organized code with separate concerns for navigation, forms, and interactions
- **Progressive Enhancement**: Works without JavaScript, enhanced with interactive features

## Styling Approach
- **Design System**: Consistent color palette, typography, and spacing
- **Component-Based**: Reusable styles for cards, buttons, and form elements
- **Mobile-First**: Responsive design starting from mobile and scaling up
- **Modern CSS**: Uses latest CSS features like custom properties, grid, and flexbox
