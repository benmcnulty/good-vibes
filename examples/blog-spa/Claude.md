# Claude Guide – Blog SPA Example

This file describes the vibe-coded plan for building the **Vibe Blog** example SPA.

## Purpose
- Demonstrate a fully functional blog platform built with vibe coding principles
- Showcase modern web development techniques using vanilla JavaScript
- Provide an example of positive, engaging user experience design

## Key Features
- **Responsive Design**: Mobile-first approach with CSS Grid and Flexbox
- **Dynamic Content**: JavaScript-powered post rendering and navigation
- **Modern Styling**: CSS custom properties, gradients, and smooth animations
- **Accessibility**: ARIA labels, semantic HTML, and keyboard navigation
- **Performance**: Optimized loading states and smooth transitions
- **User Experience**: Intuitive navigation and engaging visual design

## Technical Implementation
- **Navigation**: Single-page application with hash-based routing
- **Content Management**: JSON-based blog post data structure
- **UI Components**: Reusable post card components with consistent styling
- **Loading States**: Simulated async loading with spinners and transitions
- **Responsive Layout**: Grid-based layout that adapts to different screen sizes

## Content Strategy
- Sample blog posts focused on vibe coding philosophy and practices
- Categorized content with tags and metadata
- Engaging excerpts that encourage reading
- Consistent tone that reflects positive development culture

## Enhancement Opportunities
- Add real blog post content and routing
- Implement search and filtering functionality
- Add commenting system or engagement features
- Connect to a content management system or API
- Include social sharing capabilities
