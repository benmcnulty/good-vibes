# Next Steps: Example SPAs

This document outlines a practical enhancement for the **Good Vibes** project. The repository now includes five example SPAs demonstrating the vibe coding approach. Each example lives in the `examples/` directory with its own `index.html` and `Claude.md` file.

## Purpose
- Provide ready-to-run mini projects that showcase vibe coding principles.
- Offer starting points for future experimentation and community contributions.
- Keep each example lightweight and self-contained for easy exploration.

## Example Folders
| Folder | Description |
| --- | --- |
| `examples/portfolio-spa` | Basic portfolio site structure |
| `examples/blog-spa` | Simple blog layout with posts section |
| `examples/gallery-spa` | Image gallery starter layout |
| `examples/weather-spa` | Minimal weather dashboard |
| `examples/chat-spa` | Very small chat demo |

Each subfolder includes:
1. `index.html` – A working SPA skeleton with inline styles and navigation.
2. `Claude.md` – Documentation describing the intended features and coding approach.

## Recommended Next Steps
1. Review the new example folders and expand the documentation in each `Claude.md` as needed.
2. Use these examples to experiment with new ideas before integrating them into the main site.
3. Keep the examples modular; update the roadmap if any evolve into official modules.
4. Encourage contributions that follow the style guidelines defined in [AGENTS.md](AGENTS.md) and [CLAUDE.md](CLAUDE.md).

These examples provide a foundation for future vibe coding sessions and help illustrate how small SPAs can grow within the Good Vibes ecosystem.
